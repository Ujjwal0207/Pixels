# DesignPro — Free Graphic Design Studio (Light & Classy Edition)

**DesignPro** is an independent, clean-room, production-grade graphic design suite built entirely with modern web standards (HTML5 Canvas, Fabric.js, SVG, and Vanilla CSS). It operates completely free in your browser with zero subscription fees, user tracking, or paywalls.

---

## 🚀 Quick Launch

### Option 1: Live Local Server
Start any static file server, for example:
```bash
python3 -m http.server 3333
```
Then visit: 👉 **[http://localhost:3333/index.html](http://localhost:3333/index.html)**

### Option 2: Direct Browser Launch
You can also open [index.html](file:///Users/personal/Desktop/canva_pro/index.html) directly in any modern web browser (Chrome, Safari, Firefox, Edge).

- Removes solid or studio background colors from uploaded photos with automatic corner sampling.

- Linear (horizontal, vertical, diagonal) and radial gradients with custom hex pickers and designer presets.

### 17. Fullscreen Slide Deck Presentation Mode ("Present")
- Cinema-style fullscreen slide show mode with smooth stage backdrop.
- Minimal floating slide navigation controls: previous/next slide and slide counter.
- Keyboard navigation with Left/Right Arrows, Spacebar, and Esc.

### 18. Object Alignment & Distribution Engine ("Position / Arrange")
- Align selected object(s) Left, Center, Right, Top, Middle, and Bottom.
- Distribute 3+ objects evenly along Horizontal or Vertical axes.

- **JSON Project File (`.designpro`)**: Save your editable design project to JSON and reload anytime.
- **Print**: Direct print-to-PDF formatting.

## ⌨️ Keyboard Shortcuts

Press **`?`** in the app or click the `?` icon in the top header to view the shortcut cheat sheet:

| Shortcut | Action |
| :--- | :--- |
| `Ctrl / ⌘ + Z` | Undo |
| `Ctrl / ⌘ + Y` or `Ctrl + Shift + Z` | Redo |
| `Ctrl / ⌘ + C` | Copy Selected Object |
| `Ctrl / ⌘ + V` | Paste Copied Object |
| `Ctrl / ⌘ + D` | Duplicate Object |
| `Ctrl / ⌘ + G` | Group Selected Objects |
| `Ctrl + Shift + G` | Ungroup Selected Group |
| `Del` / `Backspace` | Delete Selected Object |
| `Ctrl / ⌘ + A` | Select All Objects |
| `Arrow Keys` | Nudge 1px |
| `Shift + Arrow Keys` | Nudge 10px |
| `Shift + Click` | Multi-Select Objects |
| `F5` / `Present Button` | Fullscreen Presentation Mode |
| `Esc` | Exit Presentation or Close Modal |
| `?` | Keyboard Shortcuts Cheat Sheet |
